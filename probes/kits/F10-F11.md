# Probes F10 and F11: Excel for Mac, one session (about 10 minutes)

Files: `probes/kits/f10/` (`f10_kit.xlsx`, `Other.xlsx`) and `probes/kits/f11/f11_kit.xlsx`.
Allow file access and link updates if Excel asks. Write down every message Excel shows.

**F10: trim ranges and references to another workbook**
1. Open `f10/Other.xlsx`, then `f10/f10_kit.xlsx`. Keep both open.
2. In f10_kit: Formulas → Name Manager → **+**, one name at a time (Scope: Workbook):
   `TrimAll` `=Sheet1!$A$1.:.$A$10` · `TrimEnd` `=Sheet1!$A$1:.$A$10` · `TrimStart` `=Sheet1!$A$1.:$A$10`
   · `TrimFn` `=TRIMRANGE(Sheet1!$A$1:$A$10)` · `Ext` `='[Other.xlsx]Sheet1'!$A$1` · `ExtName` `=Other.xlsx!OtherVal`.
   If Excel refuses one, note its message and go on.
3. On Sheet1 type into C1 … C8:
   `=ROWS(A1.:.A10)` · `=ROWS(A1:.A10)` · `=ROWS(A1.:A10)` · `=ROWS(TRIMRANGE(A1:A10))` · `=SUM(A:.A)`
   · `='[Other.xlsx]Sheet1'!$A$1` · `=Other.xlsx!OtherVal` · `=ROWS(TrimAll)+ROWS(TrimEnd)+ROWS(TrimStart)+ROWS(TrimFn)+Ext+ExtName`
   Expected: 4, 6, 8, 4, 100, 42, 7, 71. Note any cell that shows something else.
4. File → Save As → `probes/results/f10_trim_extref_mac.xlsx` (Excel Workbook). Close both files; do not save Other.xlsx.

**F11: Create from Selection**
5. Open `f11/f11_kit.xlsx`. Select A1:B34. Formulas → Create from Selection → tick **Left column** only → OK.
   Each time Excel asks whether to replace an existing name, click **Yes**.
6. Select A40:B40 (a 300-character label), Formulas → Create from Selection → Left column → OK.
7. File → Save As → `probes/results/f11_create_from_selection_mac.xlsx`. Close.
8. Put your notes (refused names, messages, cells that differ) in `probes/results/f10-f11-mac-notes.txt`.

Afterwards: `npx vitest run packages/core/test/file/probe-f10.test.ts packages/core/test/file/probe-f11.test.ts`
prints what Excel stored next to what xln assumed. Kits are made by `node probes/kits/make-kits.mjs`.
